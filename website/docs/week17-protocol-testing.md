# Week 17: Collect Your Clues
*Unit 5 - The Body Mystery Project*

This week is the quiet middle of the project.

The learner gathers clues, keeps the routine tiny, and notices what helped the plan happen or what got in the way.

:::tip This Week's Mission
- Collect clues in a one-minute format.
- Use a simple midpoint check-in.
- Remember that missed data is a clue, not a mistake.
:::

:::info Kid Version
This is clue-collecting week.

The learner does not need perfect pages. They need a simple way to notice the clue and keep going.

If a day gets missed, that still tells part of the story.
:::

:::info Technical Name
Older learners may hear:

- **did the plan happen?** for **adherence**
- **clues I collected** for **dataset**
- **what got in the way?** for **friction point**

The kid version is clearer for this project.
:::

:::warning Missed Data Is a Clue, Not a Mistake.
Missing days can show that the plan was too hard, the schedule changed, or the setup needs to get simpler.
:::

:::info Facilitator Snapshot
- Keep daily tracking to about one minute.
- Younger learners can use one metric, emoji scales, or calendar stickers.
- Midpoint review should ask what is easy, what is annoying, and whether the plan should get simpler.
- Do not use discipline or compliance language.
- Observation-only is still fully valid.
:::

## Facilitator Preparation

:::info Before You Begin
- Check that the learner's project can be tracked quickly.
- Simplify before starting if the plan still looks too complicated.
- Prepare a midpoint check-in with three questions.
- Remind the learner that privacy still applies.
:::

:::tip Facilitation Mindset
The best tracker is the one the learner can actually use.
:::

## For Younger Learners (Ages 8-9)

:::info Adapting This Week
**Simplest version of the concept:** "Collect one little clue each day."

**What to shorten or skip:**
- Use one metric only.
- Use emojis or stickers instead of long notes.

**What success looks like:**
The learner can use the tracker a few times and explain that missing a day is okay.
:::

## For Older Learners (Ages 10-12)

:::info Deeper Option
- Add the idea that a plan can be too complicated for real life.
- Let older learners compare missing data to project design issues.
- Keep the wording supportive, not performance-based.
:::

## Guided Session 1
### Make the Daily Tracker Tiny
#### Learning Goal
By the end of this session, the learner can:

- set up a fast daily tracking page
- choose a simple format they can use
- explain what clue they are collecting

---

#### Activities

**1. Choose One Tracking Style**

Options:

- one number
- one word
- one emoji
- one sticker on a calendar

Keep it to one metric by default.

---

**2. Time the Tracker**

Ask:

> "Can you do this in about one minute?"

If not, simplify it more.

---

**3. Privacy Reminder**

Say:

> "These clues belong to you. You can share only what you want to share."

---

## Guided Session 2
### Midpoint Check-In
#### Learning Goal
By the end of this session, the learner can:

- notice whether the plan feels easy or annoying
- identify what got in the way
- make the project simpler if needed

---

#### Activities

**1. Ask Three Questions**

- What is easy?
- What is annoying?
- Should I make this simpler?

These questions are enough.

---

**2. What Got in the Way?**

Possible answers:

- forgot the notebook
- too busy
- bad timing
- tracker too long
- space was noisy

Say:

> "What got in the way is useful information."

---

**3. Simplify the Plan if Needed**

Examples:

- track fewer times
- use one emoji instead of a sentence
- move the notebook
- shorten the note

## Independent Practice

### Goal

Collect a few simple clues and use the tracker with low pressure.

### Activities

**1. Daily Clue Page**

The learner can use:

- a calendar sticker
- an emoji row
- one small chart
- one quick number or word per day

**2. Reflection Choice**

Choose one:

- "The easiest part of my plan is..."
- "What got in the way was..."
- "One way to make it simpler is..."

### Body Clues Notebook

Starter page:

> **Clue I collected:** _____________
>
> **Did the plan happen?** yes / no / partly
>
> **What got in the way, if anything?** _____________
>
> **What I might simplify:** _____________

Missing days are allowed.

---

## Check for Understanding

1. Can the learner collect clues in a one-minute format?
2. Can the learner explain that missing data is a clue, not a mistake?
3. Can the learner name one way to simplify the plan?

---

## Pause and Notice

:::note What Matters Here
Ask:

> "What changed when we treated a missed day like information instead of failure?"

That question keeps the whole capstone humane.
:::
